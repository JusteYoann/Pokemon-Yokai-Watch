# Terr’heure : du déclenchement au combat

[Voir ou télécharger la vidéo MP4 avec le son](debut-terreur-jusqu-au-combat-mgba.mp4).

Enregistrement continu de **59 secondes dans mGBA**, à vitesse normale, sans coupe : grotte normale, déclenchement de la Terr’heure, disparition des habitants, décor gris et brume mobile, exploration, détection, poursuite de Gargaros et début du combat.

Repères approximatifs :

- 00:02 : déclenchement.
- 00:08 : transformation du décor.
- 00:18 : exploration.
- 00:36 : détection.
- 00:43 : transition de combat.
- 00:48 : portrait de Gargaros.
- 00:57 : menu de combat.

La position de départ, l’équipe et l’éligibilité de la première Terr’heure sont préparées pour la démonstration. Dès le début de l’enregistrement, seules les touches de la manette sont utilisées : aucune téléportation, modification du chronomètre ou victoire imposée. Le combat est déclenché par la poursuite ; le délai normal de 180 secondes est conservé.
