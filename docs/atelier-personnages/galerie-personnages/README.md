# Galerie des personnages enregistrés

Instantané du commit `1cab31bdabe3ff1dc0a5631f10e83bcb6e0732a2`. 21 personnages / formes sur carte, 15 portraits de combat, 28 autres planches. Les ressources de déplacement complètes sont dans le ZIP ; la première galerie montre les orientations de repos. Ce sont des aperçus de sources agrandis au plus proche voisin, pas des captures d’émulateur.

Les dernières modifications locales non enregistrées d’Agent X (nouvelle marche et nouveau portrait) sont volontairement exclues. La galerie montre son ancien sprite intégré. Les propositions de face A/B/C et la face aux deux yeux validée restent dans le dossier de propositions, sans être confondues avec cet état enregistré. Ce relevé ne constitue pas un retour arrière du projet.

Le ZIP contient les PNG natifs déjà présents dans cet instantané, et leur inventaire. Les sprites des 151 espèces et les anciens brouillons non retenus ne sont pas inclus dans cette galerie de personnages. L’existence d’un fichier ne vaut pas validation artistique ni vérification de son usage scénaristique.
