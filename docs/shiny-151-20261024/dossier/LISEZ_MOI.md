# Dossier refonte shiny — 151 Yo-kai

Créé pour le ROM hack « Pokémon Rouge Feu × Yo-kai Watch ».
Source de noms/évolutions : branche `codex/reprise-scenario-2026-10-22` de
`JusteYoann/Pokemon-Yokai-Watch`, consultée pour construire le dossier.

## Contenu

- `PROMPT_CODEX.md` : demande d'implémentation, validation et sécurité.
- `PALETTES_151.csv` : 151 consignes exhaustives; ID + constante interne.
- `INVENTAIRE_151.md` : même inventaire au format lisible.
- `CONSIGNES_VISUELLES.md` : exceptions, familles, et limites.
- `REFERENCES_ORIGINALES/` : 63 artworks extraits sans retouche du RAR.
- `EXTRAS/` : référence Whisperocrates et référence Sirénée/Sirénité.
- `SOURCE_ORIGINALE/` : fichier NEW SHINY.rar d'origine, pour traçabilité.

## Comptage

- **63** artworks directs.
- **29** palette héritées d'une référence familiale.
- **56** palettes décrites individuellement.
- **3** règles spéciales (Bandinyan, Épinyan, Whisper).
- **151 / 151** directions artistiques documentées.

Ni sprite ni ROM n'ont été modifiés ici. Rien n'a été fusionné sur master.
