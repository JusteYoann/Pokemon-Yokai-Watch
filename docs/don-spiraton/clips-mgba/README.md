# Clips mGBA de la finale Don Spiraton

[**Télécharger les 30 clips — ZIP sans audio**](clips-finale-don-spiraton-sans-audio.zip?raw=true)

Décompresser l’archive puis ouvrir `index.html` pour parcourir la galerie, ou
ouvrir directement les MP4 du dossier `clips`.

Entrée et discours de Don, arrivée/soin de Matt, fusion, huit Morphing,
victoire, conclusion, départ de la Mafiamille, Chen, Panthéon, crédits,
postgame, maison d’exil et revanche de Matt.

Captures réelles mGBA, équipe QA renforcée, dialogues confirmés plus lentement
pour rester lisibles. Aucun changement au jeu. Cette édition est **sans audio**
pour préserver la consigne de ne pas publier les OST privées sur GitHub.
L’archive avec le mixage original est conservée localement.
