# Pachycoul : sauvetage de Lostelle

Le Yo-kai du combat de sauvetage de Lostelle, au Bois aux Baies de l’Île 3, est désormais **Pachycoul, niveau 30**. Le cri précédant le combat correspond également à Pachycoul. Son espèce interne est SPECIES_MAGIKARP (129), selon la correspondance des 151 Yo-kai du projet.

Vérification dans mGBA : apparition de Pachycoul niveau 30 dans le vrai combat sauvage, victoire, récompense de Lostelle, retour chez son père sur l’Île 2, puis déplacements et menu START disponibles. Partie de test isolée et équipe niveau 100 ; aucune sauvegarde utilisateur modifiée. Compilation réussie.
