La nouvelle face fournie par le créateur montre un seul œil cyan à gauche de l'image. L'autre est masqué par une mèche blonde. Cette référence remplace les précédentes pour les déclinaisons présentées ici : profil gauche avec œil visible, profil droit avec œil masqué, dos, chacun au repos et avec deux pas.

Neuf PNG transparents 32 × 32, dessinés par matrices natives, dans `graphics/alyzon_bie/declinaisons-v3/`. Les profils ne sont pas de simples miroirs. Les pointes de cheveux sont évasées à hauteur des épaules ; visage plat sans nez saillant, blouse ouverte, haut violet, bas bleu sombre et pieds courts. Les têtes restent fixes durant le cycle de marche. Palette RGB555, noir opaque distinct de la transparence.

La nouvelle face du créateur n'est pas redessinée ni incluse dans cette planche. Son image source est une capture affichée dans la conversation ; les couleurs des déclinaisons sont une adaptation sur la palette native existante, pas une extraction garantie de son PNG original.

Une étude d'orientation générée avec les deux nouvelles références a été consultée pour les volumes, mais n'a pas été réduite pour fabriquer les sprites. Les pixels natifs proviennent des matrices du script `outils/construire_alyzon_nouvelle_base.py`.

Le GIF est un aperçu de poses, pas une capture mGBA. Aucun remplacement de ROM, table de sprites, scénario ou gameplay. Les versions précédentes sont conservées séparément ; cette proposition est à valider visuellement.
