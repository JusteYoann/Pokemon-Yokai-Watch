# Référence Pokémon FRLG Archipelago

Inventaire, clés symboliques, catégories et régions dérivés de https://github.com/vyneras/Archipelago/tree/3d1359cf0606cee11eebfecc0d820063bef7c2a2/worlds/pokemon_frlg (branche frlg-stable, MIT). La notice complète est conservée dans FRLG_LICENSE.txt et jointe aux APWorlds construits par make_apworld.py.

Les données de correspondance ne constituent pas une compatibilité du patch vanilla avec le fangame. Aucun base_patch.bsdiff4, ROM ou ressource graphique de cette référence n’est redistribué. Le code C du fork pokefirered de Vyneras, dépourvu de licence explicite dans l’audit, n’a pas été copié.
