Le sous-dossier `jouables/` contient seulement les trois YAML de développement à fournir au générateur. Les deux `.yaml.example` sont rangés séparément dans `en_attente/` : YW1 est un prototype non jouable et Emerald reste gelé. Ne pas fournir ce dossier au générateur. AP 0.6.9 peut lire aussi des fichiers sans extension `.yaml` : garder uniquement les trois YAML dans son dossier de joueurs. Ne pas renommer les modèles pour prétendre avoir cinq jeux prêts. YW1 bloque aussi la génération par défaut.
