# Alyzon Bie — déclinaison du sprite choisi

Face retranscrite à partir de la capture quadrillée fournie le 23 octobre 2026. Le fichier PNG natif de cette face n'est pas disponible : la transcription et les couleurs restent à comparer avec l'original du créateur, sans prétendre à une identité binaire.

Douze PNG transparents 32 × 32 dans `mouvement/` : face, dos, gauche, droite, chacun au repos et avec deux pas. Silhouette au repos de 14 × 17 pixels. Les pas prolongent une chaussure d'un pixel. Tête et torse fixes pendant la marche. Profils opposés symétriques.

Palette de seize entrées dont une transparente, export RGB555. Les contours noirs opaques sont distincts de la transparence. `overworld.png` : neuf cellules FRLG dans l'ordre face, dos, gauche, pas face 1/2, pas dos 1/2, pas gauche 1/2 ; droite par retournement horizontal. `.4bpp` : 4 608 octets ; `.gbapal` : 32 octets.

Planche et GIF : `docs/lavanville-zombie-night/phase-1/prototypes/alyzon-marche/`. Le GIF est un aperçu des poses, pas une capture mGBA. Aucune ROM, table graphique, carte ou ressource précédemment validée n'a été remplacée.
